# Dojo Survey

A simple Django application for collecting survey responses and displaying results.

## Project structure

- `manage.py` — Django management entrypoint
- `dojo_survey/` — Django project configuration
- `my_app/` — main application with models, views, URLs, and templates

## Setup

1. Create and activate a virtual environment

2. Install Django:

   ```powershell
   pip install django
   ```

## Running the app

Start the development server:

```powershell
python manage.py runserver
```

Then open `http://127.0.0.1:8000/` in your browser.
